## What is Polycule?

Polycule is a powerful Nim SDK for interacting with Polymarket's Central Limit Order Book (CLOB). Built for performance and type safety, it provides a complete toolkit for building trading bots, market makers, and analytics tools on Polymarket.

## Core Capabilities

### Trading Operations
- Create and post limit orders (BUY/SELL)
- Support for multiple order types: GTC, FOK, FAK, GTD
- Post-only orders and order book management
- Batch order creation (up to 15 orders)
- Order cancellation (single or bulk)

### Market Data
- Real-time order book updates
- Price change notifications
- Last trade price tracking
- Best bid/ask monitoring
- Tick size change alerts

### Account Management
- L1 authentication with EIP-712 signatures
- L2 HMAC-based API authentication
- Support for EOA, Proxy, and Gnosis Safe wallets
- Open orders and trade history queries

### Specialized Features
- Crypto up/down market utilities for BTC, ETH, SOL
- Automatic market switching for time-based markets
- Chainlink and Binance price feed subscriptions via RTDS
- Neg-risk and standard market support

## Architecture

Polycule is organized into focused modules:

- **clob**: CLOB API methods (L1 auth, L2 signed operations, public endpoints)
- **evm**: Smart contract interactions (CTF, Exchange, ERC20, EIP-712)
- **gamma**: Market data from Polymarket's Gamma API
- **websockets**: Real-time WebSocket channels (market, user, RTDS)
- **http_client**: HTTP client with retry logic and error handling

## Why Nim?

Nim provides:
- **Performance**: Compiles to efficient C code, near-native speed
- **Memory Safety**: Strong type system with compile-time checks
- **Async/Await**: First-class async support via chronos
- **Interop**: Easy C/C++ integration for existing trading infrastructure
- **Small Binaries**: Ideal for deployment in resource-constrained environments
