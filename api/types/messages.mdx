## BookMessage

Book message received via WebSocket (event_type="book" is implicit).

<ResponseField name="asset_id" type="string">
  Asset ID (token ID)
</ResponseField>

<ResponseField name="market" type="string">
  Condition ID of market
</ResponseField>

<ResponseField name="timestamp" type="Timestamp">
  Parse timestamp to int64
</ResponseField>

<ResponseField name="hash" type="string">
  Hash summary of orderbook content
</ResponseField>

<ResponseField name="bids" type="seq[OrderSummary]">
  Array of bid orders
</ResponseField>

<ResponseField name="asks" type="seq[OrderSummary]">
  Array of ask orders
</ResponseField>

<ResponseField name="last_trade_price" type="Price">
  Last trade price
</ResponseField>

## PriceChangeMessage

Price change message received via WebSocket (event_type="price_change" is implicit).

<ResponseField name="market" type="string">
  Condition ID of market
</ResponseField>

<ResponseField name="price_changes" type="seq[PriceChange]">
  Array of price change objects
</ResponseField>

<ResponseField name="timestamp" type="Timestamp">
  Parse timestamp to int64
</ResponseField>

### PriceChange

Nested object within PriceChangeMessage.

<ResponseField name="asset_id" type="string">
  Asset ID (token ID)
</ResponseField>

<ResponseField name="price" type="Price">
  Parse to float
</ResponseField>

<ResponseField name="size" type="Size">
  Parse to float
</ResponseField>

<ResponseField name="side" type="Side">
  Parse to Side enum
</ResponseField>

<ResponseField name="hash" type="string">
  Hash of the order
</ResponseField>

<ResponseField name="best_bid" type="Price">
  Parse to float
</ResponseField>

<ResponseField name="best_ask" type="Price">
  Parse to float
</ResponseField>

## OrderMessage

Order message received via WebSocket (event_type="order" is implicit).

<ResponseField name="asset_id" type="string">
  Asset ID (token ID) of order
</ResponseField>

<ResponseField name="associate_trades" type="seq[string]">
  Array of IDs referencing trades (can be null)
</ResponseField>

<ResponseField name="id" type="string">
  Order ID
</ResponseField>

<ResponseField name="market" type="string">
  Condition ID of market
</ResponseField>

<ResponseField name="order_owner" type="string">
  Owner of order
</ResponseField>

<ResponseField name="original_size" type="Size">
  Parse to float
</ResponseField>

<ResponseField name="outcome" type="string">
  Outcome name/description
</ResponseField>

<ResponseField name="owner" type="string">
  Owner of orders
</ResponseField>

<ResponseField name="price" type="Price">
  Parse to float
</ResponseField>

<ResponseField name="side" type="Side">
  Parse to Side enum
</ResponseField>

<ResponseField name="size_matched" type="Size">
  Parse to float
</ResponseField>

<ResponseField name="timestamp" type="Timestamp">
  Parse timestamp to int64
</ResponseField>

<ResponseField name="type" type="OrderMessageType">
  PLACEMENT/UPDATE/CANCELLATION (enum)
</ResponseField>

## CryptoPriceUpdateMessage

Crypto price update message received via WebSocket from RTDS.

<ResponseField name="connection_id" type="string">
  Connection ID
</ResponseField>

<ResponseField name="timestamp" type="Timestamp">
  Message timestamp
</ResponseField>

<ResponseField name="type" type="string">
  Message type
</ResponseField>

<ResponseField name="topic" type="string">
  Topic name
</ResponseField>

<ResponseField name="payload" type="CryptoPriceUpdatePayload">
  Payload containing price data
</ResponseField>

### CryptoPriceUpdatePayload

<ResponseField name="timestamp" type="Timestamp">
  Price timestamp in Unix milliseconds
</ResponseField>

<ResponseField name="value" type="Size">
  Current price value
</ResponseField>

<ResponseField name="full_accuracy_value" type="string">
  Full accuracy price value
</ResponseField>

<ResponseField name="symbol" type="string">
  Trading pair symbol
</ResponseField>
