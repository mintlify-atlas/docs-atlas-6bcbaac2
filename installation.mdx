## Prerequisites

Before installing Polycule, ensure you have the following:

<Steps>
  <Step title="Install Nim">
    Polycule requires Nim version 2.2.4 or higher.
    
    ```bash
    # Using choosenim (recommended)
    curl https://nim-lang.org/choosenim/init.sh -sSf | sh
    choosenim stable
    
    # Verify installation
    nim --version
    ```
    
    Visit [nim-lang.org](https://nim-lang.org/install.html) for platform-specific instructions.
  </Step>
  
  <Step title="Install Nimble">
    Nimble is Nim's package manager and is included with standard Nim installations.
    
    ```bash
    # Verify nimble is installed
    nimble --version
    ```
  </Step>
</Steps>

## Install Polycule

<Warning>
  Polycule is currently in early development and not yet published to the nimble package registry. Install from source.
</Warning>

### Install from Source

```bash
# Clone the repository
git clone https://github.com/yourusername/polycule.git
cd polycule

# Install dependencies
nimble install -d
```

### Add to Your Project

Add Polycule to your project's `.nimble` file:

```nim
requires "polycule"
```

## Dependencies

Polycule automatically installs the following dependencies:

  <Accordion title="Core Dependencies">

  </Accordion>
  
  <Accordion title="Ethereum & Crypto">
    - **eth** (>= 0.9.0): Ethereum types and utilities
    - **web3** (>= 0.8.0): Web3 provider for signing
    - **nimcrypto** (>= 0.7.3): Cryptographic primitives
    - **stint** (>= 0.8.2): Arbitrary precision integers
  </Accordion>
  
  <Accordion title="WebSocket & Logging">
    - **websock** (>= 0.2.1): WebSocket client
    - **chronicles** (>= 0.12.2): Structured logging
    - **stew** (>= 0.4.2): Standard extensions
  </Accordion>
  
  <Accordion title="Time & Utilities">
    - **timezones** (>= 0.5.4): Timezone handling for crypto markets
  </Accordion>
</AccordionGroup>

## Environment Setup

<Steps>
  <Step title="Set up environment variables">
    Create a `.env` file or export variables for your credentials:
    
    ```bash
    # Required for signing transactions
    export EOA_PRIVATE_KEY="0x..."
    
    # Required for Polygon network access
    export POLYGON_RPC="https://polygon-rpc.com"
    ```
    
    <Warning>
      Never commit private keys to version control. Use environment variables or secure key management.
    </Warning>
  </Step>
  
  <Step title="Configure your RPC provider">
    You'll need a Polygon RPC endpoint. Popular options include:
    
    - [Alchemy](https://www.alchemy.com/)
    - [Infura](https://infura.io/)
    - [Polygon's public RPC](https://polygon-rpc.com/) (rate limited)
    
    For production use, we recommend a dedicated RPC provider with higher rate limits.
  </Step>
</Steps>

## Verify Installation

Create a simple test file to verify your installation:

```nim test.nim
import polycule
import std/[os, uri]

proc main() {.async.} =
  let
    rpcUrl = parseUri(getEnv("POLYGON_RPC"))
    privateKey = PrivateKey.fromHex(getEnv("EOA_PRIVATE_KEY")).value()
  
  let client = await newPolycule(
    privateKey,
    PolyculeConfig(rpcUrl: Opt.some(rpcUrl))
  )
  
  echo "Polycule client created successfully!"
  echo "Wallet address: ", client.user.get().wallet.signer.defaultAccount

when isMainModule:
  waitFor main()
```

Run the test:

```bash
nim c -r test.nim
```

If you see your wallet address printed, installation was successful!

## Build Configuration

### Optimization Flags

For production builds, compile with optimization flags:

```bash
nim c -d:release --opt:speed --passC:-flto your_bot.nim
```

### Debug Builds

For development with full logging:

```bash
nim c -d:debug --debugger:native your_bot.nim
```
