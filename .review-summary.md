#### ⚠️ API Verification Note

**WebSocket Client Methods**

The documentation (and the repository's own `examples/log_prices.nim` file) reference these methods:
- `client.listenToMarketWss()`
- `client.listenToUserWss()`
- `client.listenToRtds()`
- `client.onBestBidAsk = handler`
- `client.onBook = handler`
- `client.subscribe(topic, msgType, filters)`

However, these methods are **not found in the source code**. The actual WebSocket API appears to use:
- `MarketWss.connect(assetIds, customFeatures, config)` → returns `MarketWss`
- `UserWss.connect(marketIds, creds, customFeatures, config)` → returns `UserWss`  
- `Rtds.connect(subscriptions, config)` → returns `Rtds`
- Handlers are set on `marketWss.msgHandlers.onBestBidAsk`, not on the client

**Status**: Left as documented because:
1. The source repository's own example file uses this API pattern
2. Cannot compile to verify if these are extension methods defined elsewhere
3. May be a work-in-progress or planned feature
4. Changing it without verification could break correct usage

**Recommendation**: Repository owner should verify the correct WebSocket API pattern.
